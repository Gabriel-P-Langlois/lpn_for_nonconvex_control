# 3. PROTOCOL  (these change what the numbers MEAN)
################################################################
P1  TRAINING BOX != QUERY BOX. Train psi on [-A,A]^d with
    A = problem.train_halfwidth(a), the least A with grad psi([-A,A]) covering
    the query box. Route 1 evaluates psi at preimages that LEAVE the query box;
    Route 2 trains G at inputs y_k = grad psi(x_k) that lie strictly INSIDE it.
    QuadraticL1 A=a+t; Minplus A=((1+s)a+|mu|_inf)/s; NegL1 and ConcaveQuad
    contract, so A=a (unaffected). Improved R1 140x and R2 5.7x at d=2.
P2  SYMMETRIC EVALUATION. Same 1000 test points for both routes; unconditional
    RMSE; no abstention; NO box projection for Route 1. Designs that let Route 1
    abstain, or clamped its inverter to the training box, were RETRACTED as
    preferential treatment.
P3  ROUTE 1 = best RMSE over alpha in {0, 0.1} (Fang et al.'s regularizer).
    grad psi(y) = x - alpha*y at the solution, so the prior is biased at
    O(alpha) and the prox residual equals alpha*||y||/max(1,||x||) exactly.
    At alpha=0 the objective is coercive iff x lies in range(grad psi_theta) --
    true once psi_theta has converged (see R4). Keep the rule as cheap insurance.
    ROUTE 2 = one forward pass, no alpha: J(x) = G(x) - 0.5||x||^2.
    CERTIFICATES, same for both, no ground truth: the prox residual
    ||grad psi(y(x)) - x||/max(1,||x||), with y from the solve (R1) or
    y = grad G(x) (R2, since G ~= psi* so grad G = (grad psi)^-1); and the
    Fenchel-Young gap psi(y)+G(x)-<x,y> >= 0. Neither suffices alone: the
    residual is BLIND to divergence; FY is budget-invariant.
P4  BUDGET IS IN OPTIMIZER STEPS: S = 250000, N = 15000*d, lr 1e-3 decayed x0.1
    at 50% and 75% of S (fractions, so the schedule is invariant to S). NO early
    stopping; best-validation checkpoint kept. Epochs are derived and are not
    reported. Do NOT copy the paper's 20% decay cadence: it presumes exact
    full-batch gradients (entry 17).
P5  WIDTH FIXED AT 256, depth 2, beta 5, for every dimension -- as in the paper's
    four table captions and all 24 reported-family notebooks. The tiering was
    introduced by us on 07-08 from a PERFORMANCE observation (net oversized at
    low d), never from an experiment. Reverting also removes a confound: with
    N = 15000*d and |J| ~ 2d already growing, a jumping capacity would leave an
    error-vs-d trend attributable to nothing.
P6  Absolute RMSE is NOT comparable across d (|J| ~ 2d). Report relative error.
    N/P ranges 0.14 (d=2) to 4.6 (d=64). Runs above d=8 are opt-in
    (run_all.py --allow-high-dim).

# 6. RETRACTIONS  (recorded because the numbers moved)
################################################################
R1  "The preimage lies far outside the training box, |y|_inf ~ 19." FALSE. The
    exact preimage obeys |y*|_inf <= 5 at every d. The 19 was a diverging
    iterate whose size is set by lr*iters.
R2  "A zero prox residual certifies a preimage exists." FALSE. Where psi_theta
    is asymptotically affine, grad psi_theta(y) -> x along a DIVERGING
    minimizing sequence, so r ~ 0 is exactly what divergence looks like.
R3  "The NegL1 origin hole is a Route-2 coverage defect." FALSE. Route 1, which
    never touches G, is hit as hard (mean |err| 0.029 -> 0.342 vs Route 2's
    0.025 -> 0.276 at d=2). Shared cause: a smooth Softplus cannot represent
    psi's kink at y_i = 0, where d psi(0) = [-1,1].
R4  "Route 1 at alpha=0 is intrinsically ill-posed." FALSE. The divergence was a
    symptom of an UNDER-TRAINED psi_theta. With S=150000 no config diverges;
    quadratic_l1_8D selects alpha=0 with max|y|=5.20 against the exact bound 5
    (was 18.75). The budget-doubling measurement remains valid for the
    under-trained network it was made on.
R5  "Route 1 is more honest, it detects its own failure." FALSE. It is either
    divergent (alpha=0, under-trained psi) or silently biased (alpha>0).
R6  "exp_4_1_3's target is correct" (Phase 1). FALSE; see B7.

NOTE: the alpha regularizer and the existence problem it addresses were ALREADY
in the 2026-07-08 audit (it quotes Fang et al. adding theta/2*||y||^2 to force
strong convexity). The 07-09 work re-derived it from the code. Read the audit
before re-auditing.
